# preserve_forbidden_combinations

Add-on for CS-Cart. Keeps forbidden combinations when an option is removed, and drops only that option from each rule. Made in Pennsylvania, USA 🇺🇸 by [Breakfast](https://breakfastco.xyz).

## Installation

Zip this repository and upload it under **Add-ons**. Leave `.git` out of the zip. The installer copies the files and installs **Preserve Forbidden Combinations**.

When you delete an option, CS-Cart deletes every forbidden combination that names it. This add-on writes those rules back without the deleted option. A rule is kept only when at least two fields are still specified.
